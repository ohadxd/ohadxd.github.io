שלב ד1 - מוסיפים לולאה עם Interval
7 דק׳

  3. כתבו 0.2 כדי שכל 0.2 שניות תתבצע פקודה.
שלב ד2 - מוסיפים את שינוי הצבע
8 דק׳
  1. לחצו על part. אם לא מצאתם, גללו למטה עם גלגלת העכבר.
  2. גררו את הפקודה change color אל תוך לולאת ה-interval.
  3. לחצו על הפלוס add instance ובחרו באפשרות הראשונה.
  4. אחר כך לחצו על זכוכית המגדלת עד שתופיע ההודעה Select.
  5. ברשימה הימנית בחרו את colorPart1.
שלב ד3 - בונים צבע חדש עם RGB
6 דק׳

כדי לבחור צבע חדש, צריך לדעת שהמחשב יוצר צבע על ידי 3 אורות בעוצמות שונות: אדום, ירוק ו-כחול. כל ערך הוא בין 0 ל-255.

  1. לחצו על world וחפשו את Color3.
  2. גררו אותו אל המקום הריק אחרי COLOR =.
שלב ד4 - מוסיפים מספרים רנדומליים
7 דק׳

  2. גררו את num אל ששת המקומות הריקים.
  3. מלאו את המספרים כמו בתמונה, כך שכל random יבחר מספר בין 0 ל-255.
