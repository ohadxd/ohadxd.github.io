🕹️ איך עובדים בעמוד?

1. מורידים Visual Studio Code.
2. מוסיפים את Codex ומתחברים.
3. מעתיקים פרומפט, מוסיפים רעיון, ובונים משחק.

1 שלב 1 - מורידים Visual Studio Code

לפני שמתחילים, צריך להוריד את Visual Studio Code. זה המקום שבו כותבים קוד, שומרים קבצים ופותחים את הפרויקט.

הורדת Visual Studio Code הקישור נפתח בלשונית חדשה ומוביל לעמוד ההורדה הרשמי.

2 שלב 2 - מוסיפים את Codex ל-Visual Studio Code

אחרי ש-VS Code מותקן, מוסיפים את תוסף Codex. התוסף פותח לכם עוזר AI בתוך סביבת העבודה, כדי שתוכלו לבנות משחקים עם הוראות פשוטות.

דף התוסף של Codex מדריך Codex הרשמי
!
נכון ל-22 במרץ 2026, במסמכי OpenAI של Codex ל-IDE מצוין שההרחבה עובדת עם משפחת GPT-5.1-Codex. אם אינכם רואים "GPT-5.2-Codex", זה תקין. בחרו את דגם Codex שמופיע אצלכם. OpenAI גם מציינת ש-Codex זמין לזמן מוגבל בחלק מחשבונות Free ו-Go, אבל לפעמים צריך חשבון אחר כדי להתחבר.

שלב א - פותחים את עמוד התוסף

חפשו את התוסף הרשמי של OpenAI בשם Codex – OpenAI's coding agent, ואז לחצו Install מתוך VS Code או מתוך ה-Marketplace.

שלב ב - מחפשים את Codex בסרגל הצד

אחרי ההתקנה, חפשו את האייקון של Codex בצד של VS Code. אם צריך, סגרו ופתחו מחדש את VS Code.

שלב ג - אם לא רואים את Codex

לפעמים צריך לשנות את כיוון סרגל הצד ל-vertical או להצמיד את Codex ידנית, כדי לראות אותו ברור.

שלב ד - מתחברים ובוחרים מודל

  1. לחצו על Codex בתוך VS Code.
  2. בחרו Sign in with ChatGPT אם זו אפשרות ההתחברות שמופיעה.
  3. אם מופיע בוחר מודלים, בחרו את דגם Codex הזמין אצלכם.
  4. אם אין גישה, בקשו עזרה מהורה או מהמורה.

3 שלב 3 - כותבים פרומפט ומתחילים לבנות

פותחים פרויקט חדש ב-VS Code.
מדביקים את הפרומפט המוכן.
מוסיפים תיאור קצר של המשחק שלכם.
נותנים ל-Codex לבנות את הקבצים.
TIP

🧰 קבצי assets להורדה

אם רוצים לבנות משחק חלליות, אפשר להתחיל מה-sprite sheet ומה-JSON שכבר מוכנים לכם. הורידו אותם, שימו בתוך תיקייה בשם assets, ואז תגידו ל-Codex להשתמש בהם.

ה-Sprite Sheet

התמונה מכילה כמה דמויות ואובייקטים קטנים של משחק חלליות.

הורדת PNG

קובץ ה-JSON

ה-JSON מסביר ל-Codex שכל תא הוא 16x16, שיש 8 עמודות, ואיזה sprite נמצא בכל אינדקס.

cell size 16px
columns 8
rows 2
sprites 12
הורדת JSON

תיקיית assets מוכנה

אם יותר נוח, הורידו הכל בבת אחת, חלצו את הקבצים, והעתיקו אותם לתוך assets/ בפרויקט שלכם.
