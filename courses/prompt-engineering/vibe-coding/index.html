🕹️ איך עובדים בעמוד?

1. מורידים Visual Studio Code.
2. פותחים תיקייה ריקה חדשה למשחק.
3. מוסיפים את Codex ומתחברים.
4. מעלים assets, מדביקים פרומפט, ובונים.

1 שלב 1 - מורידים Visual Studio Code

לפני שמתחילים, צריך להוריד את Visual Studio Code. זה המקום שבו כותבים קוד, שומרים קבצים ופותחים את הפרויקט.

הורדת Visual Studio Code הקישור נפתח בלשונית חדשה ומוביל לעמוד ההורדה הרשמי.
TIP
ברוב המחשבים בבית לוחצים על הכפתור הכחול של Windows. אם יש לכם מחשב של Apple עם סמל תפוח, לוחצים על Mac.

2 שלב 2 - מוסיפים את Codex ל-Visual Studio Code

אחרי ש-VS Code מותקן, מוסיפים את Codex מתוך VS Code עצמו. זה עוזר ה-AI שבונה איתכם את המשחק.

מדריך Codex הרשמי
!
שימו לב: Copilot ו-Codex הם לא אותו דבר. אנחנו מחפשים את Codex של OpenAI.

שלב א - לוחצים על Extensions בתוך VS Code

בתוך VS Code חפשו את סמל ה-Extensions בסרגל הצד. לוחצים עליו, ואז מחפשים Codex או OpenAI.

שלב ב - מחפשים את Codex ולא מתבלבלים

בגרסאות חדשות של VS Code הסמלים יכולים להופיע למעלה או בצד. חפשו את הסמל של Codex. אם אתם רואים סמל אחר כמו Copilot, זה לא מה שאנחנו צריכים כאן.

שלב ג - אם לא רואים את Codex

לפעמים צריך לשנות את כיוון סרגל הצד ל-vertical או להצמיד את Codex ידנית, כדי לראות אותו ברור.

שלב ד - מתחברים ובוחרים מודל

  1. לחצו על Codex בתוך VS Code.
  2. אם מופיע Sign in with ChatGPT, לחצו עליו והתחברו.
  3. אם מופיע בוחר מודלים, בחרו דגם Codex זמין.
  4. אם צריך עזרה בהתחברות, בקשו מהורה או מהמורה.

3 שלב 3 - פותחים פרויקט חדש

עכשיו פותחים תיקייה ריקה חדשה. בתוך התיקייה הזאת Codex יבנה את קבצי המשחק.

שלב א - לוחצים Open Folder

במסך הפתיחה של VS Code לוחצים על Open Folder. זה אומר: לבחור את התיקייה שבה המשחק יישמר.

שלב ב - יוצרים תיקייה חדשה ריקה

בחלון שנפתח לוחצים New folder, נותנים שם לתיקייה, ואז לוחצים Select folder. הכי טוב להתחיל מתיקייה ריקה.

TIP
איך פותחים את המשחק אחר כך? אחרי ש-Codex מסיים, פתחו את תיקיית הפרויקט ולחצו פעמיים על index.html, או גררו אותו לחלון של Chrome או Edge. המשחק צריך לעבוד בלי שרת ובלי התקנות נוספות.
מבנה קבצים פשוט להתחלה: 
project-folder/
  index.html
  style.css
  script.js
  assets/

4 שלב 4 - מוסיפים תמונות וכותבים ל-Codex

עכשיו עוברים לצ'אט של Codex. כאן מעלים תמונות וקבצים, ואז שולחים את ההודעה הראשונה.

כך נראה הצ'אט של Codex

בתחתית הצ'אט יש + להוספת קבצים. אחרי שמוסיפים תמונות או JSON, רואים אותם ככרטיסיות קטנות עם שם הקובץ.

מה עושים כאן בדיוק?

  1. לוחצים על + ומוסיפים PNG, JSON או assets אחרים.
  2. מדביקים את הפרומפט המוכן.
  3. מוסיפים את תיאור המשחק שלכם.
  4. שולחים את ההודעה עם החץ.
TIP
אם צירפתם spritesheet ו-JSON, תכתבו ל-Codex במפורש להשתמש רק בהם בתור כל ה-assets של המשחק.

אפשר לבחור מודלים נוספים

אם בחשבון שלכם מופיעים מודלים נוספים שאינם חינמיים, בדרך כלל הם חזקים יותר למשימות קשות. להתחלה אפשר לעבוד מצוין גם עם דגם Codex החינמי שמופיע אצלכם.

מה לבחור?

  1. להתחלה: בחרו דגם Codex פשוט וזמין.
  2. אם המשחק מורכב יותר: אפשר לנסות דגם מתקדם יותר שמופיע לכם.
  3. אם לא בטוחים: התחילו בדגם החינמי, ורק אחר כך נסו שדרוג.
